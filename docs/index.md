# Respect MkDocs theme

A minimalist MkDocs theme for the [Respect](https://github.com/Respect)
organization. Monochrome neutrals, the Ubuntu typeface, generous whitespace,
and a single subtle accent for interactive elements.

Start at [Installation](guide/installation.md) to add the theme to a project,
or read [Configuration](guide/configuration.md) for the supported options.

## Quick install

```bash
pip install mkdocs mkdocs-respect
```

In your `mkdocs.yml`:

```yaml
theme:
  name: respect
plugins:
  - search
```
